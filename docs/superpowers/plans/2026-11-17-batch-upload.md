# 批量上传实施计划

目标：文档入口支持一次选择多个文件，清楚显示上传限制与逐文件结果。

设计：保留单文件接口，新增受登录保护的 `/upload/limits` 和 `/upload/batch`。默认每批 10 个、单文件 50 MB、总计 100 MB（1 MB = 1024² 字节），均可通过后端环境变量配置。前端从后端获取限制，选择后先展示清单，用户点击开始上传；超限整批拒绝且不写入文档。后端按实际读取字节校验全部大小，再顺序复用单文件处理流程，单个文件的类型或解析失败不阻止其余文件。保留私有归属，不自动重试以免重复创建。

- [x] 新增上传对话框，展示数量/大小、文件清单、选择错误及每个文件的结果；上传中防止重复提交。
- [x] 调整代理大小及等待时间，更新环境模板和部署说明。
- [x] 运行后端测试、前端检查和构建；浏览器核对批量成功、部分失败、超限拦截及手机布局。

部署约束：Next 与 nginx 的请求体上限需略大于文件总量以容纳 multipart 边界，默认 110 MB；若增加业务限制，需同步增加代理上限。批量解析同步完成，代理等待设为 15 分钟，不显示虚假的逐文件实时进度。请求中断后先刷新文档列表确认结果再重传。
