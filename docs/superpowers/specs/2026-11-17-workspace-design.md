# 知识助手界面与文档工作区

用户要求在现有多用户知识库上完成整体界面更新。沿用 Next.js 与 FastAPI，采用左侧导航、中间会话、右侧单文档预览。相比弹窗预览，这能持续对照原文提问；相比多标签文档，单预览遵循用户要求，新打开的文件覆盖当前文件。

## 交互

- 左栏保留整体收起，文档与会话历史分别提供展开/收起。文档名可点击，上传与删除继续可用。
- 中间会话与右侧文档分别可收起、重新展开，隐藏会话不卸载消息与输入状态。窄屏采用切换式预览，保留返回会话入口。
- 文档区展示解析后的可读文本，保留分块、页码和引用高亮；不执行上传文档中的 HTML。文件不支持解析或为空时明确提示。
- 原文定位默认只显示查看按钮；展开后只列文件名，点击后在右栏定位引用。新请求取代旧请求，防止快速切换显示错文档。
- 设置放在侧栏底部，包含外观、退出登录、注销账号入口。注销继续使用既有邮箱验证码确认流程。
- 默认深色（黑底白字），浅色为白底黑字。选择保存在浏览器，登录、注册、找回、验证及注销页一致使用主题。
- 三个示例显示清晰的标题及实际问题，纵向排列，点击填入输入框。

## 实施约束

文档内容接口必须先检查本人或公共资料访问权限，不暴露服务器路径；其他用户私有文档返回 404。预览加载、空内容、网络错误可恢复。设置支持键盘与 Escape 关闭，收放按钮提供名称和展开状态。保留原有登录、连续提问、会话切换功能。

## 验收

验证左右收放与恢复、新建/继续会话、文档切换竞态、引用文件名展开、主题刷新与公共页面一致、设置入口，以及 390px 和桌面宽度。执行受影响后端测试、TypeScript、ESLint、生产构建与浏览器交互检查。
